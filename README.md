# 🍔 Swiggy Sales Data Analysis (Python Project)

## 📌 Project Overview

This project analyzes Swiggy food delivery data to understand customer behavior, sales trends, and revenue patterns using Python.

The goal is to extract meaningful insights such as:

* Monthly sales trends
* Customer preferences (Veg vs Non-Veg)
* Top-performing cities and states
* Daily revenue patterns

---

## 📊 Dataset Features

* Order Date
* City
* State
* Dish Name
* Price (INR)
* Rating
* Rating Count

---

## ⚙️ Tools & Technologies Used

* Python 🐍
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Plotly
* Jupyter Notebook / Google Colab

---

## 🔍 Key Analysis Performed

### 📌 KPI Metrics

* Total Sales
* Average Rating
* Average Order Value
* Total Orders
* Total Ratings Count

### 📈 Data Analysis

* Monthly Revenue Trend
* Daily Revenue Analysis (Mon–Sun)
* Veg vs Non-Veg Sales Contribution
* State-wise Revenue Analysis
* Top 5 Cities by Sales

---

## 📊 Key Insights

* Certain cities generate the highest revenue
* Non-veg items contribute significantly to total sales
* Weekend sales tend to be higher than weekdays
* Monthly trends show fluctuations in demand

2. Install dependencies:


